# Grove - RGB LED Stick (10 WS2813 Mini)

Ten-pixel addressable RGB stick with WS2813 backup-data chaining, per-pixel 200 Ω power feed and 100 nF bypassing, 220 Ω data input resistor, and bulk input capacitance.
