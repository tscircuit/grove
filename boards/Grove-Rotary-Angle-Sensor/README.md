# Grove - Rotary Angle Sensor v1.2

Recreation of the 10 kΩ WH09-2-103 potentiometer module and its analog Grove interface.

## Source fidelity

- Revision: v1.2, nominal 20 mm × 20 mm class board.
- Source: [official Seeed Eagle archive](https://files.seeedstudio.com/wiki/Grove-Rotary_Angle_Sensor/res/Grove%20-%20Rotary%20Angle%20Sensor%20v1.2.zip) and [product wiki](https://wiki.seeedstudio.com/Grove-Rotary_Angle_Sensor/).
- The schematic nets and component value follow the Eagle source. Placement, outline details, and routing are representative tscircuit geometry.
