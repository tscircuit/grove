# Board directories

Add one directory per Grove board. Follow the layout and snapshot requirements
in the repository README. Do not add a board without both its PCB and schematic
snapshot SVGs.

The first collection contains 12 commonly used Grove modules. Their individual
READMEs identify the upstream Seeed revision and public source package, explain
where a design is functional rather than an exact CAD conversion, and record
the license status of the source material.
