# Grove - OLED Display 0.96 inch (SSD1315) v1.0

128×64 monochrome OLED recreation with the official 3.3 V regulator, bidirectional I²C level shifting, SSD1315 support network, and charge-pump capacitors.

## Source fidelity

- Revision: v1.0, Grove 2U outline.
- Source: [official Seeed Eagle archive](https://files.seeedstudio.com/wiki/Grove-OLED-Display-0.96-SSD1315-/res/Grove%20-%20OLED%20Display%200.96%20(SSD1315)_v1.0.zip) and [product wiki](https://wiki.seeedstudio.com/Grove-OLED-Display-0.96-SSD1315/).
- Main values and net groups follow the Eagle schematic. The published 30-contact display tail is represented by its functional SSD1315 pins so the schematic remains reviewable; placement, outline notches, and routing are representative.
