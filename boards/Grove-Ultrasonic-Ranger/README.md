# Grove - Ultrasonic Ranger v2.0

Single-wire 40 kHz ultrasonic-ranging module with separate transmit and receive transducers and an onboard controller that multiplexes trigger and echo on Grove SIG.

## Source fidelity

- Revision: v2.0, 50 mm × 25 mm × 16 mm, Seeed Studio SKU 101020010.
- Source: [official Seeed schematic PDF](https://files.seeedstudio.com/wiki/Grove_Ultrasonic_Ranger/res/Grove_Ultrasonic%20Ranger%20Schematic.pdf) and [product wiki](https://wiki.seeedstudio.com/Grove-Ultrasonic_Ranger/).
- Seeed documents the shared SIG behavior, 40 kHz transducers, V2.0 C14 power-stability update, and dimensions, but does not publish V2.0 editable CAD on the wiki. The controller/driver block and placement are therefore a functional review model, not an exact copper clone.
- License: the published schematic PDF does not state a hardware license; Seeed attribution is retained and redistribution rights should be confirmed independently.
