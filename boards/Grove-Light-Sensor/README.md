# Grove - Light Sensor v1.2

Photoresistor divider and LM358 voltage-follower recreation of the classic analog Grove light sensor.

## Source fidelity

- Target product: Grove - Light Sensor v1.2, SKU 101020014.
- Source: [official Seeed Eagle archive](https://files.seeedstudio.com/wiki/Grove_Light_Sensor/resources/Grove%20-%20Light%20Sensor.zip) and [product wiki](https://wiki.seeedstudio.com/Grove-Light_Sensor/).
- Seeed's public archive is labeled v1.1; the v1.2 product retains the documented GL5528/LM358 signal chain. This model recreates that circuit and the 20 mm Grove form factor, not an exact v1.2 copper conversion.
- License: the downloaded hardware archive contains no explicit license file; Seeed attribution is retained and redistribution rights should be confirmed independently.
