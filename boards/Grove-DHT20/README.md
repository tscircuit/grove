# Grove - Temperature & Humidity Sensor DHT20 v2.1

DHT20 I²C sensor recreation with the published 3.3 V regulator and bidirectional 2N7002 level shifters.

## Source fidelity

- Revision: v2.1, Grove 2U outline.
- Source: [official Seeed design archive](https://files.seeedstudio.com/wiki/Grove-Temperature-Humidity-Sensor/Grove-Temperature&Humidity-Sensor-V2.1.zip) and [product wiki](https://wiki.seeedstudio.com/Grove-Temperature-Humidity-Sensor-DH20/).
- Values and net topology follow the Eagle source. Sensor/package geometry, placement, edge notches, and routing are representative tscircuit geometry.
